# Финансовая грамотность — «Питомец Финни»

Мобильное просветительское приложение для детей 7–11 лет. В игровой форме учит планировать бюджет, различать обязательные и необязательные расходы, копить на цель и делать сбережения.

**Платформа:** Android (Godot 4.7)
**Целевая аудитория:** дети 7–11 лет
**Тип:** функциональный прототип для RuStore

---

## 🎯 Что умеет

- Создание виртуального питомца (3 формы × 3 цвета = 9 комбинаций)
- Планирование бюджета на игровой период
- Покупки в двух магазинах (ближний / дальний со скидкой)
- Накопления: копилка, подушка безопасности, банк с процентами
- Финансовые задания с диалогами и выбором
- Сон, отдых и восстановление энергии питомца
- Раздел для взрослого с прогрессом
- Демонстрационный режим для экспертной проверки

---

## 🚀 Как запустить

### Требования
- Godot 4.7 или выше (stable)
- Android SDK (для сборки APK)

### Запуск в редакторе
1. Открой Godot → `Import` → выбери `project.godot`
2. Нажми **F5**
3. Игра запустится в окне 360×640

### Сборка APK
1. `Project → Export → Add → Android`
2. Укажи путь к Android SDK и keystore
3. `Export Project` → получишь `.apk`

---

## 🎮 Как играть

1. **Welcome** → знакомство
2. **CreatePet** → выбери форму и цвет питомца, дай имя
3. **Home** → главный экран с питомцем, балансом, энергией
4. **Задания** → проходи диалоги, получай монеты и опыт
5. **Бюджет** → планируй расходы и накопления на период
6. **Покупки** → покупай товары в магазине
7. **Копилка** → копи на цель, откладывай в банк
8. **Уложить спать** → завершай игровой день

---

## 🏗 Архитектура

- **Godot 4.7** — движок
- **GDScript** — язык
- **JSON** — контент (задания, товары, цели, диалоги)
- **Singleton-менеджеры:** `ProfileManager`, `ScreenManager`, `Economy`, `TaskHolder`, `PetVisual`
- **Хранение данных:** `user://profile.json` (локально, без сервера)
